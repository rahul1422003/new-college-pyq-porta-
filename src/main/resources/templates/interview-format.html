Interview Format Sheet

HR + Technical Interview Answer Format

Name: | Enrollment:

1. Self Introduction Format

  • Start with name, course, semester and college.
  • Mention 2 technical skills and 1 strength.
  • End with one project or placement goal.

2. Project Explanation Format

  • Problem statement
  • Tech stack used
  • Your contribution
  • Main challenge
  • Result / future scope

3. STAR Format

  • Situation
  • Task
  • Action
  • Result

4. Common HR Questions

  • Tell me about yourself
  • Why should we hire you?
  • What is your weakness?
  • Where do you see yourself in 5 years?
